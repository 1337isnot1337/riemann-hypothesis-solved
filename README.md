# Riemann Hypothesis Lean Archive

This repository mirrors the Lean project released by **Levent Alpöge**, who announced a proof of the Riemann Hypothesis and its Dirichlet generalization in collaboration with Claude. [Alpöge’s original announcement (PDF)](https://alpo.ge/remark.pdf)

- [Lean project](extracted/lean/) with the original toolchain and dependency pins.
- [Theorem statements and archive details](remark.md).

The project uses Lean 4.33.1. A partial independent replay verified the statement definitions and several conditional reductions. The full proof build remains unverified here.
